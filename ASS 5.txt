PART 1: Plain code without comments

import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister, transpile
from qiskit_aer import AerSimulator

def tarrataca_quantum_production_3puzzle():

    r_reg = QuantumRegister(2, name="rule")
    flag = QuantumRegister(1, name="flag")
    cr = ClassicalRegister(2, name="meas")

    qc = QuantumCircuit(r_reg, flag, cr)

    qc.x(flag)
    qc.h(flag)

    qc.h(r_reg)
    qc.barrier(label="Superposition")

    qc.x(r_reg[1])
    qc.mcx(r_reg, flag[0])
    qc.x(r_reg[1])
    qc.barrier(label="Oracle (Goal Match)")

    qc.h(r_reg)
    qc.x(r_reg)

    qc.h(r_reg[1])
    qc.cx(r_reg[0], r_reg[1])
    qc.h(r_reg[1])

    qc.x(r_reg)
    qc.h(r_reg)
    qc.barrier(label="Diffusion")

    qc.measure(r_reg, cr)

    return qc


qc = tarrataca_quantum_production_3puzzle()

print("--- Tarrataca Quantum Production System Circuit (3-Puzzle) ---")
print(qc.draw(output="text"))

simulator = AerSimulator()
compiled_qc = transpile(qc, simulator)
job = simulator.run(compiled_qc, shots=2048)
counts = job.result().get_counts()

print("\n--- Execution Results (2048 shots) ---")

rules_map = {
    "00": "Rule 0: Move Blank Left",
    "01": "Rule 1: Move Blank Right (Target Solution)",
    "10": "Rule 2: Move Blank Up",
    "11": "Rule 3: Move Blank Down"
}

for bitstring, count in sorted(counts.items(), key=lambda x: x[1], reverse=True):
    print(f"Rule Bits: {bitstring} | {rules_map.get(bitstring)} | Counts: {count}/2048 ({count/2048*100:.2f}%)")

4. Register setup
r_reg = QuantumRegister(2, name="rule")
flag = QuantumRegister(1, name="flag")
cr = ClassicalRegister(2, name="meas")

We create:
•	r_reg: Two qubits to represent four possible production rules.
•	flag: One ancilla qubit used for phase kickback.
•	cr: Two classical bits to store the selected rule.
The four rules are:
Binary	Rule
00	Move blank left
01	Move blank right
10	Move blank up
11	Move blank down
Why two qubits?
Two qubits can represent four possible combinations:
\[ 2^2=4 \]
5. Initialize the flag qubit
qc.x(flag)
qc.h(flag)
•	X gate changes the initial state from \(|0\rangle\) to \(|1\rangle\).
•	H gate creates the state \(|-\rangle\).
\[ |-\rangle=\frac{|0\rangle-|1\rangle}{\sqrt{2}} \]
This state helps the oracle mark the correct rule using phase kickback.
6. Create superposition
qc.h(r_reg)
qc.barrier(label="Superposition")
Hadamard gates are applied to both rule qubits.
This creates an equal superposition of all four possible rules:
\[ \frac{1}{2}(|00\rangle+|01\rangle+|10\rangle+|11\rangle) \]
Simple explanation: The quantum circuit considers all four candidate rules in superposition.
7. Quantum production oracle
qc.x(r_reg[1])
qc.mcx(r_reg, flag[0])
qc.x(r_reg[1])
qc.barrier(label="Oracle (Goal Match)")
The oracle identifies the correct production rule.
In our problem:
•	Initial state: [1, 2, 0, 3]
•	Goal state: [1, 2, 3, 0]
•	Correct rule: 01 (Move blank right)
The first X gate temporarily changes the most significant rule qubit so that the multi-controlled operation selects the desired 01 state.
mcx() means Multi-Controlled X gate.
It applies an X operation to the flag only when both control qubits are 1.
Because the flag is in the \(|-\rangle\) state, this operation changes the phase of the matching rule.
Important: The oracle marks the correct rule; it does not physically move the puzzle tiles.
8. Diffusion operator
qc.h(r_reg)
qc.x(r_reg)

qc.h(r_reg[1])
qc.cx(r_reg[0], r_reg[1])
qc.h(r_reg[1])

qc.x(r_reg)
qc.h(r_reg)
qc.barrier(label="Diffusion")
This is the diffusion operator used in Grover's search.
Its purpose is to increase the probability of measuring the marked rule.
The main operations are:
1.	Apply Hadamard gates.
2.	Apply X gates.
3.	Apply a controlled-Z equivalent using H-CNOT-H.
4.	Apply X gates again.
5.	Apply Hadamard gates again.
Simple explanation: The oracle marks the correct answer, and the diffusion operator amplifies its probability.
9. Measurement
qc.measure(r_reg, cr)
This measures the two rule qubits and stores the result in the classical register.
The expected selected rule is:
01

It is a tile-based puzzle in which we move numbered tiles and a blank space to reach a required goal arrangement.
Q2. What is Tarrataca's Quantum Production System?
It is a quantum approach to production-system rule selection, where candidate rules are represented using quantum states and a quantum search process.
Q3. What is a production rule?
A production rule is an action that can be applied to the current problem state to move toward the goal.

[1, 2, 3, 0]

Quantum computing concepts
Q11. What is superposition?
Superposition allows a qubit to represent a combination of possible states before measurement.
Q12. Which gate creates superposition?
The Hadamard gate.
Q13. What is a quantum oracle?
An oracle is a quantum operation that identifies or marks the correct solution.
Q14. What is the purpose of the oracle in this program?
It marks rule 01 because that rule moves the initial puzzle state to the goal state.
Q15. What is Grover's search algorithm?
Grover's algorithm is a quantum search algorithm used to find a marked item in an unsorted search space.
Q16. What is the purpose of the diffusion operator?
It increases the probability of measuring the marked solution.
Q17. What is phase kickback?
Phase kickback is a quantum effect in which a phase change is transferred to a control state through a controlled operation.
Q18. Why is the flag qubit initialized using X and H gates?
To prepare the flag qubit in the \(|-\rangle\) state for phase kickback.
Q19. What is an ancilla qubit?
An extra qubit used to support a quantum operation. Here, it is used as the oracle flag.
Q20. What is a multi-controlled X gate?
It applies an X gate to the target qubit only when all control qubits are in state 1.

Classical unstructured search generally needs \(O(N)\) queries, while Grover's search needs approximately \(O(\sqrt{N})\) oracle queries.
