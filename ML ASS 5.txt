# Import NumPy library
import numpy as np

# Step 1: Create 4x4 GridWorld Maze
# 0 represents walkable cell
# 1 represents obstacle or wall

maze = np.array([
    [0, 0, 0, 1],
    [1, 1, 0, 1],
    [0, 0, 0, 0],
    [0, 1, 1, 0]
])

# Get number of rows and columns
n_rows, n_cols = maze.shape

# Define starting and goal positions
start_state = (0, 0)
goal_state = (3, 3)

# Define four possible actions
# 0 = UP, 1 = DOWN, 2 = LEFT, 3 = RIGHT

actions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

action_names = ['UP', 'DOWN', 'LEFT', 'RIGHT']

n_actions = len(actions)

# Initialize Q-table with zeros
Q_table = np.zeros((n_rows, n_cols, n_actions))

# Step 2: Define hyperparameters

alpha = 0.8       # Learning Rate
gamma = 0.95      # Discount Factor
epsilon = 0.2     # Exploration Rate
episodes = 500    # Number of training episodes

# Step 3: Training Loop using Q-Learning

for episode in range(episodes):

    # Start every episode from the starting position
    state = start_state

    # Continue until the agent reaches the goal
    while state != goal_state:

        # Epsilon-greedy action selection
        if np.random.uniform(0, 1) < epsilon:

            # Explore: Select a random action
            action_idx = np.random.choice(n_actions)

        else:

            # Exploit: Select the action with maximum Q-value
            action_idx = np.argmax(Q_table[state[0], state[1]])

        # Execute the selected action
        dr, dc = actions[action_idx]

        next_r = state[0] + dr
        next_c = state[1] + dc

        # Check boundaries and obstacles
        if 0 <= next_r < n_rows and 0 <= next_c < n_cols and maze[next_r, next_c] == 0:

            # Move to the next valid state
            next_state = (next_r, next_c)

        else:

            # Stay in the same position if movement is invalid
            next_state = state

        # Step 4: Define rewards

        if next_state == goal_state:

            # Positive reward for reaching the goal
            reward = 100.0

        elif next_state == state:

            # Penalty for hitting a wall or boundary
            reward = -10.0

        else:

            # Small penalty for every movement
            reward = -1.0

        # Step 5: Update Q-table using Bellman equation

        max_future_q = np.max(Q_table[next_state[0], next_state[1]])

        current_q = Q_table[state[0], state[1], action_idx]

        Q_table[state[0], state[1], action_idx] = current_q + alpha * (
            reward + gamma * max_future_q - current_q
        )

        # Update current state
        state = next_state

# Step 6: Extract optimal path

optimal_path = [start_state]

current = start_state
steps = 0

# Follow the best action until the goal is reached
while current != goal_state and steps < 20:

    # Select action having maximum Q-value
    best_action = np.argmax(Q_table[current[0], current[1]])

    # Get movement direction
    dr, dc = actions[best_action]

    # Calculate next position
    current = (current[0] + dr, current[1] + dc)

    # Store the position
    optimal_path.append(current)

    steps += 1

# Step 7: Display final results

print("=== REINFORCEMENT LEARNING MAZE EXPLORATION ===")

print("Maze Layout (0: Walkable, 1: Obstacle Wall):")
print(maze)

print(f"\nStart Coordinate: {start_state} | Goal Coordinate: {goal_state}")

print(f"Optimal Trajectory Discovered ({len(optimal_path) - 1} steps):")

for i, coord in enumerate(optimal_path):

    print(f" Step {i}: {coord}")

Understanding the Q-Learning Algorithm
1. What is Reinforcement Learning?

Reinforcement Learning is a machine learning technique in which an agent learns by interacting with an environment and receiving rewards or penalties.

Real-world example: A robot learns to reach a destination while avoiding obstacles.

2. What is Q-Learning?

Q-Learning is a model-free reinforcement learning algorithm that learns the best action to take in a particular state by updating Q-values based on rewards and future expected rewards.

3. What is a Q-Table?

A Q-Table stores the expected value of taking a particular action from a particular state.

In this practical:
- Rows = 4
- Columns = 4
- Actions = 4
Therefore, the Q-table shape is:
\[
4 \times 4 \times 4 = 64
\]

4. Q-Learning Update Equation
\[
Q(s,a) \leftarrow Q(s,a)+
\alpha[r+\gamma\max Q(s',a')-Q(s,a)]
\]

Where:
- \(Q(s,a)\) = Current Q-value.
- \(\alpha\) = Learning rate.
- \(r\) = Immediate reward.
- \(\gamma\) = Discount factor.
- \(s'\) = Next state.
- \(\max Q(s',a')\) = Maximum future Q-value.
5. Understanding Hyperparameters
Parameter	Value	Meaning
Alpha (α)	0.8	Learning rate
Gamma (γ)	0.95	Discount factor
Epsilon (ε)	0.2	Exploration rate
Episodes	500	Training rounds

6. Exploration vs Exploitation
- Exploration: Agent tries random actions to discover new paths.
- Exploitation: Agent chooses the action with the highest learned Q-value.
The epsilon-greedy strategy balances both.

A. Reinforcement Learning Basics
Q1. What is Reinforcement Learning?

Reinforcement Learning is a type of machine learning where an agent learns by interacting with an environment and receiving rewards or penalties.

Q2. What is Q-Learning?

Q-Learning is a model-free reinforcement learning algorithm used to learn the optimal action for each state.

Q3. Is Q-Learning supervised or unsupervised?

It is neither supervised nor unsupervised. It belongs to Reinforcement Learning.

Q4. What is an agent?

An agent is the learner or decision-maker that interacts with the environment.

Q5. What is an environment?

An environment is the world in which the agent performs actions and receives rewards.

Q6. What is a state?

A state represents the current position or situation of the agent.

Q7. What is an action?

An action is a movement or decision taken by the agent.

Q8. What is a reward?

A reward is feedback given to the agent after performing an action.

Q9. What is a policy?

A policy is a strategy that tells the agent which action to take in a particular state.

Q10. What is the goal of Reinforcement Learning?

The goal is to learn a policy that maximizes the total expected reward.
B. Q-Learning and Q-Table
Q11. What is a Q-value?

A Q-value represents the expected future reward for taking a particular action in a particular state.

Q12. What is a Q-Table?

A Q-Table stores Q-values for different state-action combinations.

Q13. Why do we initialize the Q-table with zeros?

We initialize it with zeros because the agent has no previous knowledge about the environment.

Q14. What is the Bellman equation?

It is an equation used to update the Q-value based on the current reward and the maximum expected future reward.

Q15. What is model-free learning?

Model-free learning means the agent does not require a predefined model of the environment to learn optimal actions.

Q16. What is the difference between Q-Learning and Supervised Learning?
Q-Learning	Supervised Learning
Learns through rewards	Learns from labelled data
Uses trial and error	Uses training examples
Finds optimal actions	Predicts outputs
Reinforcement learning	Supervised learning

C. Hyperparameters
Q17. What is the learning rate (Alpha)?

Alpha controls how much new information is used when updating the Q-value.

Q18. What is the discount factor (Gamma)?

Gamma determines how much importance the agent gives to future rewards.

Q19. What is epsilon?

Epsilon is the probability of selecting a random action during exploration.

Q20. What is an episode?

An episode is one complete training attempt from the starting state until the goal state is reached.

Q21. What is epsilon-greedy strategy?

It is an action-selection strategy in which the agent sometimes chooses random actions and otherwise chooses the action with the highest Q-value.

Q22. What happens if gamma is zero?

The agent considers only immediate rewards and ignores future rewards.

Q23. What happens if alpha is zero?

The Q-values will not be updated, so the agent cannot learn from experience.
