Assignment 7 – Stock Price Time Series Analysis and Forecasting Using ARIMA
Assignment Number: 07 | Dataset: Stock_Prices.csv

Problem Statement: To analyze stock price time-series data by calculating moving averages, daily returns and annualized volatility, applying the ARIMA forecasting model to predict future stock prices, and visualizing actual prices, moving averages and predicted prices.

Libraries Used:
- Pandas – Data manipulation and time-series analysis.
- NumPy – Numerical calculations.
- Matplotlib – Data visualization.
- Statsmodels – ARIMA forecasting model.

1. Python Code – Without Comments
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.arima.model import ARIMA


# 1. Load Stock Price Time Series Data

df_stock = pd.read_csv("Stock_Prices.csv")

df_stock["Date"] = pd.to_datetime(df_stock["Date"])

df_stock.set_index("Date", inplace=True)


# 2. Compute Rolling Moving Averages & Returns

df_stock["MA_20"] = df_stock["Close"].rolling(window=20).mean()

df_stock["MA_50"] = df_stock["Close"].rolling(window=50).mean()

df_stock["Daily_Return"] = df_stock["Close"].pct_change()

annualized_vol = df_stock["Daily_Return"].std() * np.sqrt(252)


# 3. Fit ARIMA(1, 1, 1) Model for Forecasting

series_close = df_stock["Close"]

arima_model = ARIMA(series_close, order=(1, 1, 1))

arima_result = arima_model.fit()


forecast_horizon = 15

forecast_values = arima_result.forecast(steps=forecast_horizon)

forecast_dates = pd.date_range(
    start=df_stock.index[-1] + pd.Timedelta(days=1),
    periods=forecast_horizon,
    freq="B"
)

forecast_series = pd.Series(
    forecast_values.values,
    index=forecast_dates
)


print("=== STOCK TIME SERIES DIAGNOSTICS ===")

print(f"Sample Observations: {len(df_stock)} Trading Days")

print(
    f"Base Close: ${df_stock['Close'].iloc[0]:.2f} | "
    f"Latest Close: ${df_stock['Close'].iloc[-1]:.2f}"
)

print(f"Annualized Volatility: {annualized_vol * 100:.2f}%")

print("\n--- 15-Day Forward ARIMA(1,1,1) Forecast ---")

print(
    pd.DataFrame({
        "Forecast_Close": np.round(forecast_series.head(5), 2)
    })
)


# 4. Plot Time-Series Trends, Indicators, and Predictions

plt.figure(figsize=(12, 6))

plt.plot(
    df_stock.index,
    df_stock["Close"],
    label="Actual Close Price",
    color="navy",
    alpha=0.7
)

plt.plot(
    df_stock.index,
    df_stock["MA_20"],
    label="20-Day Moving Average",
    color="darkorange",
    linewidth=1.5
)

plt.plot(
    df_stock.index,
    df_stock["MA_50"],
    label="50-Day Moving Average",
    color="green",
    linewidth=1.5
)

plt.plot(
    forecast_series.index,
    forecast_series,
    label="15-Day ARIMA Forecast",
    color="crimson",

plt.title(
    "Stock Price Trend, Moving Averages, and ARIMA Forecast",
    fontsize=12,

plt.xlabel("Date")

plt.grid(True, linestyle="--", alpha=0.5)

plt.tight_layout()

plt.savefig("stock_price_analysis.png", dpi=200)

2. Python Code – With Comments and Explanation
# Import required libraries

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.arima.model import ARIMA


# 1. Load Stock Price Time Series Data

# Read stock price data from CSV file
df_stock = pd.read_csv("Stock_Prices.csv")

# Convert Date column into datetime format
df_stock["Date"] = pd.to_datetime(df_stock["Date"])

# Set Date as the index of the DataFrame
df_stock.set_index("Date", inplace=True)


# 2. Compute Rolling Moving Averages & Returns

# Calculate 20-day moving average of closing prices
df_stock["MA_20"] = df_stock["Close"].rolling(window=20).mean()

# Calculate 50-day moving average of closing prices
df_stock["MA_50"] = df_stock["Close"].rolling(window=50).mean()

# Calculate daily percentage returns
df_stock["Daily_Return"] = df_stock["Close"].pct_change()

# Calculate annualized volatility using 252 trading days
annualized_vol = df_stock["Daily_Return"].std() * np.sqrt(252)


# 3. Fit ARIMA(1, 1, 1) Model for Forecasting

# Select closing price time series
series_close = df_stock["Close"]

# Create ARIMA model with order (1, 1, 1)
arima_model = ARIMA(series_close, order=(1, 1, 1))

# Train the ARIMA model
arima_result = arima_model.fit()


# Define forecasting period as 15 days
forecast_horizon = 15

# Predict the next 15 values
forecast_values = arima_result.forecast(steps=forecast_horizon)

# Generate future business dates
forecast_dates = pd.date_range(
    start=df_stock.index[-1] + pd.Timedelta(days=1),
    periods=forecast_horizon,
    freq="B"
)

# Create a Pandas Series containing forecast values and dates
forecast_series = pd.Series(
    forecast_values.values,
    index=forecast_dates
)


# Display Stock Time Series Diagnostics

print("=== STOCK TIME SERIES DIAGNOSTICS ===")

# Display total number of observations
print(f"Sample Observations: {len(df_stock)} Trading Days")

# Display first and latest closing prices
print(
    f"Base Close: ${df_stock['Close'].iloc[0]:.2f} | "
    f"Latest Close: ${df_stock['Close'].iloc[-1]:.2f}"
)

# Display annualized volatility as a percentage
print(f"Annualized Volatility: {annualized_vol * 100:.2f}%")

# Display first five forecasted stock prices
print("\n--- 15-Day Forward ARIMA(1,1,1) Forecast ---")

print(
    pd.DataFrame({
        "Forecast_Close": np.round(forecast_series.head(5), 2)
    })
)


# 4. Plot Time-Series Trends, Indicators, and Predictions

# Create a figure with width 12 and height 6
plt.figure(figsize=(12, 6))

# Plot actual closing prices
plt.plot(
    df_stock.index,
    df_stock["Close"],
    label="Actual Close Price",
    color="navy",
    alpha=0.7
)

# Plot 20-day moving average
plt.plot(
    df_stock.index,
    df_stock["MA_20"],
    label="20-Day Moving Average",
    color="darkorange",
    linewidth=1.5
)

# Plot 50-day moving average
plt.plot(
    df_stock.index,
    df_stock["MA_50"],
    label="50-Day Moving Average",
    color="green",
    linewidth=1.5
)

# Plot predicted stock prices
plt.plot(
    forecast_series.index,
    forecast_series,
    label="15-Day ARIMA Forecast",
    color="crimson",
    linestyle="--",
    linewidth=2
)

# Set graph title
plt.title(
    "Stock Price Trend, Moving Averages, and ARIMA Forecast",
    fontsize=12,
    fontweight="bold"
)

# Set X-axis and Y-axis labels
plt.xlabel("Date")
plt.ylabel("Price ($)")

# Display grid lines
plt.grid(True, linestyle="--", alpha=0.5)

# Display graph legend
plt.legend(loc="upper left")

# Adjust graph layout
plt.tight_layout()

# Save graph as an image
plt.savefig("stock_price_analysis.png", dpi=200)

# Display the graph
plt.show()

4. SPPU Practical Viva Questions and Answers
These questions are based on the actual code and concepts used in Assignment 7.
A. Basic Time-Series Questions
Q1. What is Time Series Analysis?

Answer: Time Series Analysis is a technique used to analyze data collected over a period of time to identify trends, patterns and future values.

Q2. What is Time Series Data?

Answer: Time Series Data is data collected at regular or irregular time intervals, such as daily stock prices, monthly sales or yearly temperature.

Q3. What is the objective of this assignment?

Answer: The objective is to analyze historical stock prices, calculate moving averages and volatility, and forecast future stock prices using the ARIMA model.

Q4. What is stock price forecasting?

Answer: Stock price forecasting is the process of predicting future stock prices using historical market data.

Q5. Which Python libraries are used in this assignment?

Answer:
- Pandas – Data handling.
- NumPy – Mathematical calculations.
- Matplotlib – Data visualization.
- Statsmodels – Time-series forecasting.
B. Moving Average and Returns
Q6. What is Moving Average?

Answer: Moving Average is a statistical technique that calculates the average of data points over a fixed time period to identify trends and reduce short-term fluctuations.

Q7. What is a 20-Day Moving Average?

Answer: It calculates the average closing stock price over the previous 20 trading days.

Q8. What is a 50-Day Moving Average?

Answer: It calculates the average closing stock price over the previous 50 trading days.

Q9. What is the difference between MA_20 and MA_50?

Answer:
MA_20	MA_50
Uses 20 trading days.	Uses 50 trading days.
Shows short-term trends.	Shows relatively long-term trends.
Reacts faster to price changes.	Reacts more slowly to price changes.

Q10. What is the use of rolling()?

Answer: The rolling() function creates a moving window over data to calculate statistics such as mean and standard deviation.

Q11. What is Daily Return?

Answer: Daily Return represents the percentage change in stock price compared to the previous trading day.

Q12. What is the use of pct_change()?

Answer: It calculates the percentage change between the current value and the previous value.

Q13. What is Volatility?

Answer: Volatility measures how much stock prices fluctuate over a particular period. Higher volatility means greater price fluctuations.

Q14. What is Annualized Volatility?

Answer: Annualized Volatility estimates the yearly standard deviation of stock returns using daily return data.

Q15. Why do we use 252 in annualized volatility?

Answer: The stock market generally has approximately 252 trading days in a year.

Formula:
\[
Annualized\ Volatility = \sigma_{daily}\times\sqrt{252}
\]

C. ARIMA Model Questions
Q16. What is ARIMA?

Answer: ARIMA stands for AutoRegressive Integrated Moving Average. It is a statistical model used for time-series forecasting.

Q17. Why do we use ARIMA?

Answer: ARIMA is used to analyze historical time-series data and predict future values based on previous observations and patterns.

Q18. What are the three parameters of ARIMA?

Answer:

ARIMA (p, d, q)
- p = AutoRegressive order.
- d = Degree of differencing.
- q = Moving Average order.
Q19. What is AutoRegressive (AR)?

Answer: AutoRegressive uses previous observations to predict future values.

Q20. What is Integrated (I)?

Answer: Integrated represents differencing applied to the data to make a non-stationary time series stationary.

Q21. What is Moving Average (MA) in ARIMA?

Answer: Moving Average uses previous forecast errors to improve future predictions.

Q22. What does ARIMA(1,1,1) mean?

Answer:
- p = 1: Uses one previous observation.
- d = 1: Applies first-order differencing.
- q = 1: Uses one previous forecast error.
Q23. What is Stationarity?

Answer: A time series is stationary when its statistical properties, such as mean and variance, remain approximately constant over time.

Q24. Why is differencing required in ARIMA?

Answer: Differencing helps remove trends and makes non-stationary data more suitable for ARIMA modelling.

Q25. What is the use of fit()?

Answer: The fit() function trains the ARIMA model using historical stock price data.

Q26. What is the use of forecast()?

Answer: It predicts future values based on the trained ARIMA model.

Q27. What does forecast_horizon = 15 mean?

Answer: It specifies that the model should predict the next 15 time periods.

Q28. What is the use of ARIMA(series_close, order=(1,1,1))?

Answer: It creates an ARIMA model using the closing price series with parameters p=1, d=1 and q=1.
