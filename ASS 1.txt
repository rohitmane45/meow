PART 2 — CODE WITH COMMENTS AND EXPLANATION
A. Code with comments

# Import required libraries
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

# Function to generate 16-bit quantum random numbers
def generate_16bit_qrng(shots=5):

    # Initialize 16 qubits
    n_qubits = 16

    # Create quantum circuit with 16 qubits and 16 classical bits
    qc = QuantumCircuit(n_qubits, n_qubits)

    # Apply Hadamard gate to all qubits
    qc.h(range(n_qubits))

    # Measure all qubits and store results in classical bits
    qc.measure(range(n_qubits), range(n_qubits))

    # Create a quantum simulator
    simulator = AerSimulator()

    # Compile the quantum circuit for the simulator
    compiled_circuit = transpile(qc, simulator)

    # Execute the circuit for the specified number of shots
    job = simulator.run(compiled_circuit, shots=shots, memory=True)

    # Get the execution result
    result = job.result()

    # Extract binary measurement results
    bitstrings = result.get_memory()

    # Return circuit and generated random numbers
    return qc, bitstrings


# Generate 5 random 16-bit numbers
qc, random_bitstrings = generate_16bit_qrng(shots=5)

# Display generated random numbers
print("--- Generated 16-bit Quantum Random Numbers ---")

# Convert each binary number into decimal and hexadecimal
for i, bitstring in enumerate(random_bitstrings, 1):

    # Convert binary into decimal
    decimal_val = int(bitstring, 2)

    # Convert decimal into hexadecimal
    hex_val = hex(decimal_val).upper()

    print(f"Sample {i}:")
    print(f" Binary : {bitstring}")
    print(f" Hex : {hex_val}")
    print(f" Decimal: {decimal_val}\n")
B. Explanation of important lines
1. Import libraries
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
•	QuantumCircuit: Creates a quantum circuit.
•	transpile: Converts the circuit into instructions suitable for the selected simulator.
•	AerSimulator: Simulates quantum circuits locally.
2. Initialize qubits
n_qubits = 16
qc = QuantumCircuit(n_qubits, n_qubits)
Creates a quantum circuit containing:
•	16 quantum bits (qubits).
•	16 classical bits (to store measurement results).
3. Apply Hadamard gate
qc.h(range(n_qubits))
Applies the Hadamard gate to all 16 qubits.
It puts each qubit into an equal superposition of 0 and 1.
Therefore, each qubit has a 50% probability of measuring 0 and a 50% probability of measuring 1.
4. Measure qubits
qc.measure(range(n_qubits), range(n_qubits))
Measures all 16 qubits and stores their results in the corresponding classical bits.
Measurement converts the quantum state into classical binary results.
5. Create simulator
simulator = AerSimulator()
Creates a local quantum simulator to execute the quantum circuit.
6. Transpile circuit
compiled_circuit = transpile(qc, simulator)
Converts the quantum circuit into a format supported by the simulator.
7. Execute circuit
job = simulator.run(compiled_circuit, shots=shots, memory=True)
Executes the circuit.
•	shots=5 means the circuit runs five times.
•	memory=True stores the individual measurement results.
8. Get results
result = job.result()
bitstrings = result.get_memory()
Extracts the individual binary outputs generated by the quantum simulator.
9. Binary to decimal conversion
decimal_val = int(bitstring, 2)
Converts the binary number into decimal.
Here, 2 represents the binary number system.
10. Decimal to hexadecimal conversion
hex_val = hex(decimal_val).upper()
Converts the decimal number into hexadecimal and changes the letters to uppercase.

A. Basic Quantum Computing Questions
Q1. What is a Qubit?
Ans: A qubit is the basic unit of quantum computing. Unlike a classical bit, which can be either 0 or 1, a qubit can exist in a superposition of both states.
Q2. What is Quantum Computing?
Ans: Quantum computing is a type of computing that uses quantum bits and quantum principles to perform computations.
Q3. What is the difference between a bit and a qubit?
Ans:
Classical Bit	Qubit
Stores 0 or 1	Can exist in superposition
Used in classical computers	Used in quantum computers
Classical operations	Quantum gates
Q4. What is a Quantum Circuit?
Ans: A quantum circuit is a sequence of quantum gates applied to qubits to perform a quantum computation.
Q5. What are the different types of registers?
Ans: There are two main types:
1.	Quantum Register: Stores qubits.
2.	Classical Register: Stores measurement results in classical bits.
Q6. What is a Hadamard Gate?
Ans: A Hadamard gate is a quantum gate that creates an equal superposition of 0 and 1 when applied to a qubit initially in state 0.
Q7. What is Superposition?
Ans: Superposition is a quantum property in which a qubit can exist in a combination of the states 0 and 1 until measured.
Q8. How do you measure a qubit?
Ans: We use the measurement operation to convert the quantum state into a classical result, either 0 or 1.
