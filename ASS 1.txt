2. Code – With Comments and Explanation
import pandas as pd
import json

# 1. Load data from CSV, Excel and JSON files

df_transactions = pd.read_csv("sales_transactions.csv")

df_catalog = pd.read_excel("product_catalog.xlsx", sheet_name="Products")

df_feedback = pd.read_json("customer_feedback.json")


# 2. Data Cleaning and Type Conversion

# Convert Date column into datetime format
df_transactions["Date"] = pd.to_datetime(df_transactions["Date"])

# Convert Quantity into numeric format
df_transactions["Quantity"] = pd.to_numeric(
    df_transactions["Quantity"], errors="coerce"
)

# Convert UnitPrice into numeric format
df_transactions["UnitPrice"] = pd.to_numeric(
    df_transactions["UnitPrice"], errors="coerce"
)


# 3. Transform and Merge Data

# Merge transactions with product catalog
df_merged = df_transactions.merge(
    df_catalog, on="ProductID", how="left"
)

# Merge the result with customer feedback
df_merged = df_merged.merge(
    df_feedback, on="TransactionID", how="left"
)


# 4. Feature Calculations

# Calculate Gross Revenue
df_merged["GrossRevenue"] = (
    df_merged["Quantity"] * df_merged["UnitPrice"]
)

# Replace missing discount values with zero
df_merged["DiscountPct"] = df_merged["DiscountPct"].fillna(0.0)

# Calculate Net Revenue after discount
df_merged["NetRevenue"] = (
    df_merged["GrossRevenue"] * (1 - df_merged["DiscountPct"])
)


# 5. Business Analytics

print("=== MERGED & PROCESSED SALES DATA ===")

# Select required columns for displaying results
cols_to_show = [
    "TransactionID",
    "ProductName",
    "Category",
    "Quantity",
    "GrossRevenue",
    "NetRevenue",
    "PaymentMode"
]

print(df_merged[cols_to_show].to_string(index=False))


# Group data according to Region
print("\n--- Summary by Region ---")

# Calculate total orders, net revenue and average rating
regional_summary = df_merged.groupby("Region").agg(
    TotalOrders=("TransactionID", "count"),
    TotalNetRevenue=("NetRevenue", "sum"),
    AvgRating=("CustomerRating", "mean")
).reset_index()

# Display regional summary
print(regional_summary.to_string(index=False))


# 6. Save Unified Dataset to CSV

df_merged.to_csv("unified_sales_analysis.csv", index=False)
Explanation of Important Concepts
Code / Function	Explanation
pd.read_csv()	Reads data from a CSV file.
pd.read_excel()	Reads data from an Excel file.
pd.read_json()	Reads data from a JSON file.
pd.to_datetime()	Converts data into date format.
pd.to_numeric()	Converts values into numeric format.
errors="coerce"	Converts invalid values into NaN.
merge()	Combines two DataFrames.
how="left"	Keeps all records from the left DataFrame.
fillna(0.0)	Replaces missing values with zero.
groupby()	Groups data based on a column.
agg()	Performs aggregate calculations.
to_string()	Displays DataFrame as formatted text.
to_csv()	Saves the DataFrame into a CSV file.
Important formula:
Gross Revenue:
\[ GrossRevenue = Quantity \times UnitPrice \]
Net Revenue:
\[ NetRevenue = GrossRevenue \times (1-DiscountPct) \]
Here, DiscountPct is assumed to be in decimal form. For example, 10% is represented as 0.10.

4. SPPU Practical Viva Questions and Answers
These questions cover the oral questions given in your manual (page 13), along with additional questions directly related to the program and its concepts.
A. Basic Questions
Q1. What is Data Visualization?
Answer: Data Visualization is the process of representing data in graphical formats like charts, graphs and plots to understand information easily.
Q2. What are the different methods used in Data Visualization?
Answer:
1.	Bar Chart
2.	Pie Chart
3.	Line Chart
4.	Histogram
5.	Scatter Plot
6.	Box Plot
Q3. What is Data Analysis?
Answer: Data Analysis is the process of collecting, cleaning and processing raw data to extract useful information and make better decisions.
Q4. What is Data Cleaning?
Answer: Data Cleaning is the process of identifying and correcting incorrect, missing, duplicate or inconsistent data.
Q5. What is Data Transformation?
Answer: Data Transformation is the process of converting data from one format or structure into another suitable format for analysis.
B. Python and Pandas Questions
Q6. What is Pandas?
Answer: Pandas is an open-source Python library used for data manipulation, cleaning and analysis.
Q7. What is a DataFrame?
Answer: A DataFrame is a two-dimensional tabular data structure containing rows and columns, similar to an Excel spreadsheet.
Q8. Why do we use import pandas as pd?
Answer: It imports the Pandas library and gives it a short name pd, which makes it easier to use its functions.
Q9. What is the difference between CSV, Excel and JSON?
Answer:
•	CSV: Stores tabular data in comma-separated text format.
•	Excel: Stores spreadsheet data in workbook and worksheet format.
•	JSON: Stores data in key-value pairs and structured objects.
Q10. What is the use of read_csv()?
Answer: It is used to read data from a CSV file and load it into a Pandas DataFrame.
Q11. What is the use of read_excel()?
Answer: It is used to read data from Excel files.
Q12. What is the use of read_json()?
Answer: It is used to read JSON data into a Pandas DataFrame.
C. Data Cleaning and Transformation
Q13. What is a missing value?
Answer: A missing value is a data entry that is empty or unavailable. In Pandas, it is generally represented as NaN.
Q14. What is the use of fillna()?
Answer: It replaces missing values with a specified value, such as zero or the mean.
Q15. What is the use of to_datetime()?
Answer: It converts a column into a proper date and time format.
Q16. What is the use of to_numeric()?
Answer: It converts a column into numeric values such as integers or floating-point numbers.
Q17. What is errors="coerce"?
Answer: It converts invalid values into NaN instead of generating an error.
Q18. What is Data Merging?
Answer: Data Merging is the process of combining two or more datasets using a common column.
Q19. What is the difference between inner join and left join?
Answer:
•	Inner Join: Returns only matching records from both datasets.
•	Left Join: Returns all records from the left dataset and matching records from the right dataset.
Q20. What is the use of groupby()?
Answer: It groups records based on a particular column so that we can perform calculations on each group.
D. Business Analytics and Output
Q21. What is Gross Revenue?
Answer: Gross Revenue is the total amount before applying discounts.
Q22. What is Net Revenue?
Answer: Net Revenue is the final amount after deducting discounts.
Q23. Why do we use agg()?
Answer: The agg() function is used to perform multiple aggregate operations like sum, count and mean on grouped data.
Q24. What is the use of reset_index()?
Answer: It converts the grouped index back into a normal column in the DataFrame.
Q25. Why do we use to_csv()?
Answer: It saves the processed DataFrame into a CSV file for future use.
Q26. What is the difference between count() and sum()?
Answer:
•	count() counts non-missing values.
•	sum() calculates the total of numeric values.
Q27. Why do we use index=False?
Answer: It prevents Pandas from saving the DataFrame index as an additional column in the CSV file.
