import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import load_iris

iris = load_iris()
X = iris.data

feature_names = ['SepalLengthCm', 'SepalWidthCm', 'PetalLengthCm', 'PetalWidthCm']

df_iris = pd.DataFrame(X, columns=feature_names)

print("Dataset Overview (First 5 Rows):")
print(df_iris.head())

wcss = []
k_range = range(1, 11)

for k in k_range:
    kmeans = KMeans(
        n_clusters=k,
        init='k-means++',
        max_iter=300,
        n_init=10,
        random_state=42
    )

    kmeans.fit(X)
    wcss.append(kmeans.inertia_)

plt.figure(figsize=(8, 4.5))
plt.plot(k_range, wcss, marker='o', linestyle='-', color='b')

plt.title('The Elbow Method for Optimal K (Iris Dataset)', fontsize=12, fontweight='bold')
plt.xlabel('Number of Clusters (K)')
plt.ylabel('WCSS (Inertia)')
plt.xticks(k_range)
plt.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()

plt.savefig('iris_elbow_method.png', dpi=200)
plt.show()

optimal_k = 3

kmeans_optimal = KMeans(
    n_clusters=optimal_k,
    init='k-means++',
    max_iter=300,
    n_init=10,
    random_state=42
)

cluster_labels = kmeans_optimal.fit_predict(X)

df_iris['Cluster'] = cluster_labels

print("\n--- Elbow Method Inertia (WCSS) Values ---")

for k, inertia in zip(k_range, wcss):
    print(f"K = {k:2d} -> WCSS (Inertia) = {inertia:.2f}")

print(f"\nOptimal Number of Clusters Determined: {optimal_k}")
print(f"Cluster Distribution: {np.bincount(cluster_labels)}")

2. Code With Comments and Explanation
# Import required libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.cluster import KMeans
from sklearn.datasets import load_iris

# Step 1: Load the Iris dataset
iris = load_iris()

# Store input features
X = iris.data

# Define feature names
feature_names = [
    'SepalLengthCm',
    'SepalWidthCm',
    'PetalLengthCm',
    'PetalWidthCm'
]

# Create DataFrame
df_iris = pd.DataFrame(X, columns=feature_names)

# Display first five rows
print("Dataset Overview (First 5 Rows):")
print(df_iris.head())

# Step 2: Determine optimal K using Elbow Method
wcss = []

# Test cluster values from 1 to 10
k_range = range(1, 11)

for k in k_range:

    # Create K-Means model
    kmeans = KMeans(
        n_clusters=k,
        init='k-means++',
        max_iter=300,
        n_init=10,
        random_state=42
    )

    # Train the model
    kmeans.fit(X)

    # Store WCSS value
    wcss.append(kmeans.inertia_)

# Step 3: Plot the Elbow Curve
plt.figure(figsize=(8, 4.5))

plt.plot(
    k_range,
    wcss,
    marker='o',
    linestyle='-',
    color='b'
)

# Add graph title and labels
plt.title(
    'The Elbow Method for Optimal K (Iris Dataset)',
    fontsize=12,
    fontweight='bold'
)

plt.xlabel('Number of Clusters (K)')
plt.ylabel('WCSS (Inertia)')

# Display K values on X-axis
plt.xticks(k_range)

# Display grid
plt.grid(True, linestyle='--', alpha=0.5)

plt.tight_layout()

# Save the Elbow graph
plt.savefig('iris_elbow_method.png', dpi=200)

# Display graph
plt.show()

# Step 4: Apply K-Means using optimal K = 3
optimal_k = 3

# Create final K-Means model
kmeans_optimal = KMeans(
    n_clusters=optimal_k,
    init='k-means++',
    max_iter=300,
    n_init=10,
    random_state=42
)

# Fit the model and predict cluster labels
cluster_labels = kmeans_optimal.fit_predict(X)

# Add cluster labels to DataFrame
df_iris['Cluster'] = cluster_labels

# Step 5: Display WCSS values
print("\n--- Elbow Method Inertia (WCSS) Values ---")

for k, inertia in zip(k_range, wcss):
    print(f"K = {k:2d} -> WCSS (Inertia) = {inertia:.2f}")

# Display optimal number of clusters
print(f"\nOptimal Number of Clusters Determined: {optimal_k}")

# Display number of samples in each cluster
print(f"Cluster Distribution: {np.bincount(cluster_labels)}")

Understanding the Elbow Method
The Elbow Method is used to find the optimal number of clusters (K).
- First, we calculate WCSS for different K values.
- Then, we plot K against WCSS.
- We identify the point where the decrease in WCSS starts becoming slower.
- This point looks like an elbow and indicates a suitable K value.
What is WCSS?

WCSS stands for Within-Cluster Sum of Squares.

It measures the sum of squared distances between data points and their respective cluster centroids.
\[
WCSS = \sum_{i=1}^{K}\sum_{x\in C_i}
||x-\mu_i||^2
\]

Where:
- K = Number of clusters.
- \(C_i\) = Individual cluster.
- \(x\) = Data point.
- \(\mu_i\) = Cluster centroid.
Important: Lower WCSS means data points are closer to their cluster centroids. However, WCSS generally decreases as K increases, so we use the Elbow Method rather than simply choosing the lowest value.

3. SPPU Practical Viva Questions and Answers
A. Basic Clustering Concepts
Q1. What is clustering?

Clustering is an unsupervised machine learning technique used to group similar data points into clusters.

Q2. What is K-Means clustering?

K-Means is an unsupervised machine learning algorithm that divides data into K clusters based on similarity and distance from cluster centroids.

Q3. Is K-Means supervised or unsupervised?

K-Means is an unsupervised learning algorithm because it does not require labelled data.

Q4. What is the main objective of K-Means?

The main objective is to divide data into clusters such that data points within the same cluster are as similar as possible.

Q5. What does K represent in K-Means?

K represents the number of clusters we want to create.

Q6. What is a centroid?

A centroid is the center point of a cluster. It is calculated as the mean of all data points belonging to that cluster.

Q7. What is the difference between classification and clustering?
Classification	Clustering
Supervised learning	Unsupervised learning
Uses labelled data	Uses unlabelled data
Predicts predefined classes	Discovers groups in data
Example: Spam detection	Example: Customer segmentation

Q8. What are the main steps of K-Means?
1. Select the number of clusters K.
2. Initialize K centroids.
3. Assign each data point to its nearest centroid.
4. Recalculate centroids.
5. Repeat until centroids stop changing significantly.
Q9. What is Euclidean distance?

Euclidean distance is the straight-line distance between two points.
\[
d(x,y)=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

Q10. What are the applications of K-Means?
1. Customer segmentation.
2. Image segmentation.
3. Document clustering.
4. Market analysis.
5. Pattern recognition.
B. Elbow Method and WCSS
Q11. What is the Elbow Method?

The Elbow Method is a technique used to determine the optimal number of clusters in K-Means by plotting WCSS against different K values.

Q12. Why do we use the Elbow Method?

We use it to find a suitable number of clusters without selecting K randomly.

Q13. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares. It measures the sum of squared distances between data points and their cluster centroids.

Q14. What happens to WCSS when K increases?

WCSS generally decreases as the number of clusters increases because data points become closer to their respective centroids.

Q15. Why is it called the Elbow Method?

It is called the Elbow Method because the graph looks like a human elbow at the point where the reduction in WCSS starts slowing down.

Q16. What is the optimal K in this practical?

The optimal K is 3.

Q17. What is the difference between WCSS and centroid?
- WCSS measures the total squared distance within clusters.
- Centroid represents the center of a cluster.
C. K-Means Parameters
Q18. What is n_clusters?

It specifies the number of clusters to be created.

Q19. What is init='k-means++'?

It is an initialization technique that selects initial centroids in a way that generally improves clustering.

Q20. What is max_iter=300?

It specifies the maximum number of iterations allowed for one K-Means run.

Q21. What is n_init=10?

It means the K-Means algorithm runs 10 times with different centroid initializations and selects the best result based on inertia.

Q22. What is random_state=42?

It ensures reproducible results by fixing the random initialization.

Q23. What is the use of fit_predict()?

It trains the K-Means model and returns the cluster label assigned to each data point.

Q24. What is the difference between fit() and fit_predict()?
- fit() trains the model.
- fit_predict() trains the model and returns cluster assignments.
