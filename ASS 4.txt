PART 1: Plain code (without comments)

import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister, transpile
from qiskit_aer import AerSimulator

def run_bit_flip_qec_experiment(error_prob=0.15, shots=4000):

    data = QuantumRegister(3, name="data")
    ancilla = QuantumRegister(2, name="ancilla")
    syn_reg = ClassicalRegister(2, name="syndrome")
    res_reg = ClassicalRegister(1, name="result")

    qc = QuantumCircuit(data, ancilla, syn_reg, res_reg)

    qc.ry(np.pi / 3, data[0])
    qc.barrier(label="Prep")

    qc.cx(data[0], data[1])
    qc.cx(data[0], data[2])
    qc.barrier(label="Encode")

    qc.x(data[1])
    qc.barrier(label="BitFlip")

    qc.cx(data[0], ancilla[0])
    qc.cx(data[1], ancilla[0])

    qc.cx(data[1], ancilla[1])
    qc.cx(data[2], ancilla[1])

    qc.measure(ancilla[0], syn_reg[0])
    qc.measure(ancilla[1], syn_reg[1])
    qc.barrier(label="Syndrome")

    with qc.if_test((syn_reg, 1)):
        qc.x(data[0])

    with qc.if_test((syn_reg, 3)):
        qc.x(data[1])

    with qc.if_test((syn_reg, 2)):
        qc.x(data[2])

    qc.barrier(label="Correction")

    qc.cx(data[0], data[1])
    qc.cx(data[0], data[2])
    qc.measure(data[0], res_reg[0])

    return qc


qc = run_bit_flip_qec_experiment()

simulator = AerSimulator()
compiled_qc = transpile(qc, simulator)
job = simulator.run(compiled_qc, shots=4000)
counts = job.result().get_counts()

logical_counts = {"0": 0, "1": 0}
syndrome_stats = {}

for bitstring, count in counts.items():
    parts = bitstring.split()
    res_bit = parts[0]
    syn = parts[1]

    logical_counts[res_bit] += count
    syndrome_stats[syn] = syndrome_stats.get(syn, 0) + count

print("--- 3-Qubit QEC Circuit ---")
print(qc.draw(output="text"))

print("\n--- Syndrome Measurement Detected ---")
for syn, c in syndrome_stats.items():
    print(f"Syndrome (s1s0 = {syn}): {c} occurrences (Error identified on data[1])")

print("\n--- Corrected Logical State Measurement ---")
p0 = logical_counts['0'] / 4000
p1 = logical_counts['1'] / 4000

print(f"Logical |0_L>: {logical_counts['0']} shots ({p0 * 100:.2f}%)")
print(f"Logical |1_L>: {logical_counts['1']} shots ({p1 * 100:.2f}%)")
print("Target Theory : P(|0_L|) = 75.00%, P(|1_L|) = 25.00%")
Compatibility note: Your PDF uses the older .c_if() syntax. I have replaced it with Qiskit's if_test() conditional blocks for newer Qiskit versions. The correction logic is unchanged.

3. Define quantum and classical registers
data = QuantumRegister(3, name="data")
ancilla = QuantumRegister(2, name="ancilla")

syn_reg = ClassicalRegister(2, name="syndrome")
res_reg = ClassicalRegister(1, name="result")

qc = QuantumCircuit(data, ancilla, syn_reg, res_reg)
We create:
•	3 data qubits: Store the encoded quantum information.
•	2 ancilla qubits: Help detect errors.
•	2 classical bits: Store the error syndrome.
•	1 classical bit: Store the final logical measurement.
Why three data qubits?
Because the three-qubit repetition code stores one logical qubit across three physical qubits. It can detect and correct a single bit-flip error.
4. State preparation
qc.ry(np.pi / 3, data[0])
qc.barrier(label="Prep")
The RY gate rotates the first qubit around the Y-axis.
It prepares the state:
\[ |\psi\rangle = \cos(\pi/6)|0\rangle+ \sin(\pi/6)|1\rangle \]
Therefore:
\[ P(0)=75\%,\qquad P(1)=25\% \]
The barrier separates the preparation stage from the next stage.
5. Encoding
qc.cx(data[0], data[1])
qc.cx(data[0], data[2])
qc.barrier(label="Encode")
Here, we use two CNOT gates to encode the original state into three qubits.
The encoded state becomes:
\[ |\psi_L\rangle = \alpha|000\rangle+\beta|111\rangle \]
Simple explanation: Instead of storing information in one qubit, we distribute it across three qubits.
6. Introduce bit-flip error
qc.x(data[1])
qc.barrier(label="BitFlip")
The X gate flips the state of the second data qubit.
For example:
•	\(|0\rangle\) becomes \(|1\rangle\).
•	\(|1\rangle\) becomes \(|0\rangle\).
This deliberately introduces an error on data[1].
7. Syndrome extraction
qc.cx(data[0], ancilla[0])
qc.cx(data[1], ancilla[0])

qc.cx(data[1], ancilla[1])
qc.cx(data[2], ancilla[1])
The two ancilla qubits check the parity between pairs of data qubits.
•	Ancilla 0 checks data[0] and data[1].
•	Ancilla 1 checks data[1] and data[2].
Next, measure the ancilla qubits:
qc.measure(ancilla[0], syn_reg[0])
qc.measure(ancilla[1], syn_reg[1])
qc.barrier(label="Syndrome")
The measurement results form a two-bit syndrome.
What is a syndrome?
A syndrome is a set of measurement results that helps identify whether an error occurred and where it occurred.
8. Active error correction
with qc.if_test((syn_reg, 1)):
    qc.x(data[0])

with qc.if_test((syn_reg, 3)):
    qc.x(data[1])

with qc.if_test((syn_reg, 2)):
    qc.x(data[2])
The program checks the syndrome and applies an X gate to the affected qubit.
Syndrome (s1s0)	Meaning	Correction
00	No error	No correction
01	Error on data[0]	Apply X to data[0]
11	Error on data[1]	Apply X to data[1]
10	Error on data[2]	Apply X to data[2]
In our experiment, the X gate was deliberately applied to data[1].
Therefore, the expected syndrome is 11, and the program applies another X gate to data[1] to correct the error.
9. Decoding and final measurement
qc.cx(data[0], data[1])
qc.cx(data[0], data[2])

qc.measure(data[0], res_reg[0])
•	The CNOT gates decode the logical state.
•	The first data qubit is measured.
•	The final measurement helps us check whether the original probability distribution has been recovered.

12. Calculate probabilities

We divide the number of occurrences by total shots to calculate probabilities.
For example:
\[ P(0)=\frac{\text{Number of 0 results}}{4000} \]

PART 4: Practical viva questions and answers
These are focused on the actual concepts and code used in this assignment.
Basic concepts
Q1. What is Quantum Error Correction?
Quantum Error Correction is a technique used to detect and correct errors in quantum information caused by noise or unwanted changes.
Q2. Why do we need quantum error correction?
Quantum computers are sensitive to noise. Even small disturbances can change qubit states and produce incorrect results.
Q3. What is a bit-flip error?
A bit-flip error changes:
•	\(|0\rangle\) into \(|1\rangle\).
•	\(|1\rangle\) into \(|0\rangle\).
Q4. Which quantum gate is used to create a bit-flip error?
The Pauli-X gate.
Q5. What is the purpose of the three-qubit repetition code?
It stores one logical qubit across three physical qubits so that a single bit-flip error can be detected and corrected.
Q6. What is a logical qubit?
A logical qubit is quantum information encoded across multiple physical qubits.
Q7. What are physical qubits?
Physical qubits are the actual individual qubits used to represent and process quantum information.
Q8. What is an ancilla qubit?
An ancilla qubit is an additional qubit used to help perform operations such as error detection.
Q9. What is a syndrome?
A syndrome is the measurement result used to identify the type or location of an error.
Q10. How many data qubits are used in this assignment?
Three data qubits.
Q11. How many ancilla qubits are used?
Two ancilla qubits.
Q12. How many classical bits are used for syndrome measurement?
Two classical bits.
Questions related to the code
Q13. What is the purpose of the RY gate?
It rotates a qubit around the Y-axis and prepares a superposition state.
Q14. Why is np.pi / 3 used?
It represents an angle of 60 degrees in radians.
Q15. What is the purpose of the CNOT gate?
A CNOT gate flips the target qubit when the control qubit is 1.
Q16. Why are two CNOT gates used during encoding?
To distribute the original quantum information across three data qubits.
Q17. What is the encoded state?
\[ |\psi_L\rangle=\alpha|000\rangle+\beta|111\rangle \]
Q18. Why do we use ancilla qubits?
To extract parity information and identify errors without directly measuring the encoded data qubits.
Q19. What is parity?
Parity tells us whether two bits are equal or different.
Q20. What is the purpose of qc.barrier()?
It separates different circuit stages and helps organize the circuit.
Q21. What is if_test() used for?
It executes a quantum operation only when a specified classical condition is satisfied.
Q22. Why do we apply X again during correction?
Because applying X twice returns the qubit to its original state:
\[ X \times X = I \]
Q23. What is the purpose of transpile()?
It converts the quantum circuit into a form suitable for execution on the selected backend.
Q24. What is AerSimulator()?
It is a Qiskit simulator used to execute quantum circuits on a classical computer.
Q25. What does shots=4000 mean?
The circuit is executed 4,000 times to collect measurement statistics.
Syndrome and error correction
Q26. What are the four possible syndromes?
•	00: No error.
•	01: Error on data[0].
•	11: Error on data[1].
•	10: Error on data[2].
Q27. What syndrome is generated when data[1] has a bit-flip error?
11.
Q28. How does the program identify the error on data[1]?
Both parity checks detect a mismatch, producing syndrome 11.
Q29. Which gate corrects the error on data[1]?
The Pauli-X gate applied to data[1].
Q30. Can this three-qubit code correct two bit-flip errors?
No. It is designed to correct a single bit-flip error. Two errors can cause incorrect decoding.
Advanced practical questions
Q31. What is the difference between error detection and error correction?
Error detection identifies that an error has occurred. Error correction identifies the error and applies an operation to recover the information.
Q32. Does quantum error correction directly copy a qubit three times?
No. The quantum no-cloning theorem prevents copying an arbitrary unknown quantum state. The repetition code uses entanglement to encode the information.
Q33. What is the difference between bit-flip and phase-flip errors?
•	Bit-flip error: Changes \(|0\rangle\) to \(|1\rangle\) or vice versa.
•	Phase-flip error: Changes the relative phase of a quantum state.
Q34. Can this code correct phase-flip errors?
Not by itself. This basic repetition code is designed to correct bit-flip errors.
Q35. What is the role of error_prob=0.15 in this program?
It is a function parameter intended to represent an error probability. However, the supplied code does not use it to introduce stochastic errors.
Q36. What is the role of NoiseModel and pauli_error?
They are Qiskit Aer tools for defining noise models and Pauli error channels. They are imported in this PDF but are not actually used in the experiment.
Q37. Why is the final output approximately 75% and 25%?
Because the original state was prepared with those theoretical measurement probabilities, and the bit-flip error was corrected.
Q38. What happens if no error occurs?
The syndrome is 00, and no correction gate is applied.
Q39. What is the purpose of decoding?
Decoding reverses the encoding operations to recover the logical information in the original data qubit.
Q40. What is the main objective of this assignment?
To demonstrate how a three-qubit repetition code detects a single bit-flip error using syndrome measurement and corrects it using conditional X gates.
